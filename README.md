# 🎮 Silksong Checklist

Site feito para acompanhar o progresso feito no jogo Hollow Knight: Silksong através de checklists

## 📂 Funcionalidades
- Checklist funcionais
- Salvamento automático do progresso
- Botão para desmarcar as checklists
- Pesos para os items referentes a porcentagem do jogo
- Design inspirado na HUD do jogo original
- Redirecionamento para a wiki do jogo com maiores informações

## 🛠 Tecnologias
- HTML
- CSS
- JavaScript
